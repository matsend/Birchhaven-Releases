# Birchhaven – visuella produktionskrav

Läs [den bindande visuella målbilden](docs/visual-contract.md) före varje grafisk ändring.
Ägarens artwork är facit. Anpassa tekniken efter originalen och bevara detaljnivån.
Rapportera aldrig grafiken som färdig utan en verklig spelskärmbild som har
jämförts sida vid sida med rätt original. Spara jämförelsen och ange kvarvarande
avvikelser. Kodtester och spelbarhet räcker inte som visuell acceptans.

Den publicerade spelversionens status avgörs av GitHub Releases och verifierade
uppdateringsmanifest. Granskningsgrenar får inte beskrivas som publicerade speluppdateringar.
